# In motion · design study 04

The preceding Sourcebook iteration is archived intact at `archive/03-sourcebook/`.

The direction is a live, dark workspace. Its visual material persists across views: a folded point ribbon opens into a frame for actual projects; the same material becomes a geographic globe for the travel journal. Floating project windows carry real screenshots and come forward into usable embeds. Clear profile navigation and CV access remain available at the top. The optional terminal controls the same routes through real commands.

## Reference study

- Bruno Simon — https://bruno-simon.com/ — spatial exploration connected to ordinary controls. The live WebGL reference exceeded the software browser's shader budget; it was not used as a successful full visual review.
- Henry Heffernan — https://henryheffernan.com/ — inspected the working 3D desk/CRT introduction in Chrome. A meaningful object becomes the doorway into content. The homepage applies that principle to actual project windows.
- Dennis Snellenberg — https://www.dennissnellenberg.com/ — large typography, restrained navigation and motion hierarchy. No portrait/layout was copied.
- Lusion — https://lusion.co/ — dimensional project storytelling. The software-browser visit stalled on its loader; project structure was available through its public pages.
- Marc's Aloha pitch and ASTRA/OPUS variants — continuity between scenes, damped settling and persistent visual material. These supplied the most relevant motion reference. No fictional architecture or clinical mechanisms were added to the homepage.

## Core choices

Near-black, warm type, ice-blue light and restrained copper. Actual project screenshots and public live experiences provide the visual content. NixOS is shown through the exact public source because there is no verified current desktop screenshot. Authored articles are omitted because none were supplied; the Aloha team report remains a clearly labeled original-source link.

A visitor can read the current degree and employer immediately, open a CV immediately, or enter a running project. The command interface supports users who enjoy the terminal without making commands a prerequisite for everyone else.

This is a local design review. No Git push, hosting change, new Site registration, account connection or publication was performed.
