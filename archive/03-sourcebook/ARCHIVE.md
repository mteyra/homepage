# Sourcebook — archived design study 03

Preserved on 14 November 2026 before the next homepage redesign.

The original `index.html`, `atlas-studio.html`, complete `assets/` directory, README, design documents, source evidence and review screenshots are included. Fonts, CV, country geometry and the engineering-study dataset are local to this copy.

The only navigation adjustment changes the archived homepage's three gallery links from `archive/` to `../`, so they reach the shared design archive. Project routes, readers and Atlas Studio remain inside this version. The current homepage's assets are not required.

Open this directory through an HTTP server:

```sh
python3 -m http.server 8874
```

From the repository root, visit `http://localhost:8874/archive/03-sourcebook/`. The reading room is at `#library`, and the engineering reader is at `#read/aloha-study`.
