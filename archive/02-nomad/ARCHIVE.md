# Nomad’s Station — archived design study 02

Preserved on 14 November 2026 before the next homepage redesign.

This directory contains the original `index.html`, `atlas-studio.html`, complete `assets/` directory, README, design documents and review screenshots from that point in time. The Three.js modules, fonts, CV and country geometry are included. No runtime asset depends on the current homepage directory.

Open `index.html` through an HTTP server. Atlas Studio’s back links and preview navigation stay within this archived version. A route preview uses the browser tab’s session storage; no route dataset is included by default.

From the repository root:

```sh
python3 -m http.server 8874
```

Then open `http://localhost:8874/archive/02-nomad/`.
