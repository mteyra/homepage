# Connections — preserved 15 November 2026

This snapshot preserves the three-ring Connections homepage before its simplification into a calmer, chapter-based Orbit design.

Open `index.html` through a local HTTP server, or open `puzzle/` directly. Its page, mechanism, content, fonts, Three.js modules and public CV are copied locally. The original README and design records are preserved as historical documentation.

The only changes to the copied application are navigation paths: the Design archive links return to the parent gallery, and the legacy Atlas Studio preview handoff resolves to the existing `../04-in-motion/` archive. The regular Connections experience does not depend on that older snapshot. External credentials, repositories and LinkedIn links still use their original public destinations.

`preview.webp` is the verified final Connections desktop screenshot from 14 November, captured at 1440 × 900. The source file hashes at the time of copying are recorded in `snapshot-manifest.json`; navigation rebasing and this archive documentation were added afterwards.

Earlier archive snapshots have not been changed.
